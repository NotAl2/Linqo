# Security reports

Linqo is in active development. Please report suspected vulnerabilities privately to **aryandurgude123@gmail.com** with affected version, reproducible steps and impact. Do not post exploit details, private saves, credentials or payment records in public issues.

Use synthetic data and systems you are authorised to test. Do not test payment-provider infrastructure, other users' accounts or destructive attacks. There is no promised bounty. The local-first app has optional connected services; a completed code review or secret scan is not a guarantee that it has no vulnerabilities.

Keep copies of important content and encrypted backups. Forgotten backup passwords cannot be recovered. See the privacy and access/refund policies for data and support requests.
